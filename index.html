PyTorch Implementation: Step 01 — Token & Positional Embeddings

                            nn.Embedding
                        

                        

                            Input string is tokenized via bert-base-uncased into integer Token IDs. These are looked up in parallel embedding tables (E_token + E_pos) before entering the transformer encoder blocks.
                        

                        
class DemoGPT(nn.Module):
    def __init__(self, config):
        super().__init__()
        self.token_embedding_layer = nn.Embedding(config["vocabulary_size"], config["d_embed"])
        self.positional_embedding_layer = nn.Embedding(config["context_size"], config["d_embed"])

    def forward(self, token_ids):
        _, tokens_num = token_ids.shape
        x = self.token_embedding_layer(token_ids)
        positions = torch.arange(tokens_num, device=token_ids.device)
        pos_embed = self.positional_embedding_layer(positions)
        return x + pos_embed.unsqueeze(0)

Nanodegree Capstone

                    

                        Background notes on the development and evaluation of SentimentScope.
                    

                


                

                    

                        Project Overview
                        
Building a Lightweight Custom Transformer from Scratch

                        

                            This project was developed as the capstone submission for the Machine Learning Nanodegree. Instead of relying on monolithic pretrained Transformer wrappers, SentimentScope implements a custom multi-head self-attention architecture (DemoGPT) from PyTorch primitives, evaluated on movie sentiment benchmarks.
                        

                    


                    

                        Engineering Considerations
                        

                            To ensure lightweight free-tier cloud deployment on resource-constrained containers, model dependencies and checkpoints were optimized to operate under tight RAM bounds while preserving high sequence evaluation speed.
